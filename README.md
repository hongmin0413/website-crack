# 小遊戲攻略索引

收集各種小遊戲的破解／自動遊玩腳本，包含對戰 AI 的棋類遊戲，也包含單人限時問答這類非對戰型遊戲。每款遊戲一個資料夾，裡面有給人看的 `攻略.md`（規則、手動遊玩技巧、自動遊玩腳本簡介）跟自動遊玩腳本 `autoplay-bot.js`；程式碼層級的細節（引擎還原、演算法、除錯心得）另外放在 `.claude/<遊戲>/notes.md`，不影響一般遊玩，維護/開發時再看。

使用方式：比對下表關鍵字找到網址，`navigate` 過去，讀對應的 `攻略.md` 開始玩；需要用到自動遊玩腳本或找新破解路線時，再讀對應的 `notes.md` 取用程式碼。
